🎯 Mission
先讀機場 Wi-Fi 指示，再完成 eSIM 連線
你要讀機場網站的 Wi-Fi 步驟，先找到正確網路並登入；如果代碼失效或訊號太弱，再向服務台求助。
成功條件：找出 Airport_Guest、免費使用三十分鐘、更新後的登入代碼與重新啟動手機這個下一步；說出 “Could you help me connect to Wi-Fi?” / “Should I try again?”。
英文輸入：airport website instructions + help-desk conversation

單句模式

I arrive at the airport early for my evening flight. I need internet before I leave for my destination. I open the airport website on my phone. The page says the airport offers free Wi-Fi. The network name is Airport_Guest. Guest access lasts for thirty minutes. The page tells me to open a browser after connecting. Then select Guest Access and tap Continue. A small code appears under the instructions. I save the code before putting my phone away. I want to connect to Wi-Fi before finding my gate.

I turn on Wi-Fi and choose Airport_Guest. The sign-in page opens, but the code box is empty. I type the code from the airport website. The page asks me to select guest access. I select Guest Access and tap Continue. The page does not move. I walk to the help desk near Gate Twelve. Could you help me connect to Wi-Fi? Of course. Please show me the page. I show the guide and point to the code. The code changed this morning. Please use the new code under Guest Access.

I enter the new code and try again. This time, the page shows a welcome message. The free connection ends after thirty minutes. I check the time before I activate my eSIM. The signal is weak beside the large window. I move closer to the help desk. My phone still cannot connect to the network. Please restart your phone, then try again. I restart my phone and wait one minute. The signal becomes stronger near the desk. Now I connect to Wi-Fi and activate my eSIM.

💡 Learning Tips
  • 今天最值得直接背的是 Could you help me connect to Wi-Fi?；在機場、飯店或咖啡店都能套用。
